This directory host COMPLETE sample parsers

Refrain from uploading incomplete/work-in-progress parsers by placing a
`.gitignore` with the following content into your parser directory:

```
# Exclude everything in this directory
*
# If you want to announce your parser
# The following line exclude the .gitignore itself so the directory
# itself and the .gitignore file can be published
# !.gitignore
```
